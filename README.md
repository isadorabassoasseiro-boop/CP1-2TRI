## Problema

Com a grande quantidade de filmes disponíveis atualmente, pode ser difícil para os usuários organizarem e acompanharem os títulos que já assistiram. Muitas vezes essas informações ficam espalhadas ou acabam sendo esquecidas.

## Solução

O MovieTV foi desenvolvido como uma aplicação web simples para ajudar o usuário a organizar os filmes que já assistiu.

A aplicação apresenta um catálogo de filmes, permite pesquisar títulos e adicionar filmes a uma lista pessoal de assistidos. Dentro dessa lista, o usuário também pode realizar buscas e voltar ao catálogo para adicionar novos filmes.

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- Vite
- React Router
- React Icons

## API utilizada

O projeto utiliza a API do **TMDB (The Movie Database)** para obter informações dos filmes exibidos no catálogo, como título e imagem.

## Funcionalidades

- Tela inicial de apresentação do MovieTV
- Tela de login
- Navegação entre as páginas
- Catálogo de filmes
- Carregamento de filmes através da API TMDB
- Busca de filmes pelo nome
- Adição de filmes à lista de assistidos
- Visualização dos filmes adicionados
- Busca entre os filmes da lista de assistidos
- Retorno ao catálogo para adicionar novos filmes

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL-DO-REPOSITORIO
```

### 2. Entre na pasta do projeto

```bash
cd MOVIE-TV
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Abra no navegador

Após executar o projeto, acesse o endereço informado pelo Vite no terminal.
